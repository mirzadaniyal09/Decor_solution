# Decor Solution

Monorepo with separate frontend and backend folders.

## Structure

- client/ - Vite React frontend
- server/ - Node/Express backend

## Notes

This repo is not configured for Vercel deployment. Use your own hosting for frontend and backend.

## Local development

Frontend:

1. cd client
2. npm install
3. npm run dev

Backend:

1. cd server
2. npm install
3. npm run dev
